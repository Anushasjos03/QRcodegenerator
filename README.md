
# Custom QR Code Generator

A customizable QR Code Generator that allows you to generate QR codes with custom colors, shapes, and optional logo images. Users can input URLs or text to create QR codes with adjustable foreground and background colors, different dot shapes, and embedded images.

## Features
- Generate QR codes by entering text or URL
- Customize the foreground and background colors
- Choose between different QR code shapes (square or dots)
- Option to upload a logo to embed in the QR code
- Responsive design for mobile and desktop

## Setup
To run this project locally:

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/custom-qr-code-generator.git
    cd custom-qr-code-generator
    ```

2. Make sure the dependencies are available (hosted via CDN):
   - [qr-code-styling library](https://cdn.jsdelivr.net/npm/qr-code-styling@1.5.0/lib/qr-code-styling.js) is included in `index.html`

3. Open `index.html` in your browser:
   ```bash
   open index.html

## Usage

Enter the text or URL in the input field.
Select the foreground and background colors.
Choose the QR code shape (square or dots).
Optionally, upload a logo image to embed in the QR code.
Click the Generate QR Code button to create your customized QR code, which will appear below.
